# Construction Portfolio Website & Admin Dashboard

A full-stack construction portfolio web application featuring a public landing page with rich sections and an administrative dashboard for full content management.

---

## 🛠 Tech Stack

- **Frontend**: React 18 / 19, TypeScript, Vite, Tailwind CSS, Redux Toolkit Query (RTK Query), Lucide React.
- **Backend**: Node.js, Express 5, TypeScript, Prisma ORM v6 (`@prisma/client`), MySQL.
- **Media / Storage**: Local static assets (`public/images`) for initial seed and offline evaluation; ImageKit for dynamic admin media uploads.

---

## 🚀 Quick Setup & Installation

### 1. Prerequisites
- **Node.js**: v18+ (v20+ recommended)
- **MySQL Server**: running locally (e.g. MySQL 8.0 on port 3306)

---

### 2. Environment Variables Configuration

#### Backend (`backend/.env`)
Create or edit `backend/.env` with your MySQL connection string and credentials:
```env
PORT=5000
DATABASE_URL="mysql://root:YOUR_PASSWORD@localhost:3306/construction_portfolio"
JWT_SECRET="your-super-secret-jwt-key-change-in-production"
JWT_EXPIRES_IN="1h"
COOKIE_NAME="access_token"
FRONTEND_ORIGIN="http://localhost:5173"
NODE_ENV=development

# ImageKit credentials (Required when creating/updating images in the Admin Dashboard)
IMAGEKIT_PUBLIC_KEY=your_imagekit_public_key
IMAGEKIT_PRIVATE_KEY=your_imagekit_private_key
IMAGEKIT_ENDPOINT_URL=https://ik.imagekit.io/your_id
```
---

### 3. Database Initialization & Seeding

Navigate into the `backend/` directory:
```bash
cd backend
npm install
```

#### Step A: Push Database Schema
Push the Prisma schemas directly to your MySQL database (this creates all tables and relationships):
```bash
npx prisma db push
```

#### Step B: Populate the Database with the Seed Script
Run the automated seed script to populate all sections (Hero, About, Services, Records, Projects, Categories, Company Profile, and the default Admin account):
```bash
npm run seed
```

> **What does the seed script do?**
> - Bypasses external ImageKit uploads by pointing image URLs directly to high-resolution local assets placed inside `frontend/public/images/`.
> - Fills dummy image IDs (`local-seed-*`) so no third-party API call is required for the seed to complete.
> - Creates an administrative account:
>   - **Email**: `admin@example.com`
>   - **Password**: `AdminPassword123!`

---

### 4. Running the Project

#### Start the Backend Server:
From the `backend/` directory:
```bash
npm run dev
```
The backend server runs on `http://localhost:5000`.

#### Start the Frontend Client:
In a separate terminal, navigate into `frontend/`:
```bash
cd frontend
npm install
npm run dev
```
The frontend will start on `http://localhost:5173` (or `http://localhost:5174`). Open the URL in your browser.

## 🔑 Administrative Dashboard Access

1. Open the website in your browser.
2. In the top navigation bar, click the **Account / User icon** button on the right side and select **Sign In** (or navigate directly to `/login`).
3. Sign in with the seeded admin credentials:
   - **Email**: `admin@example.com`
   - **Password**: `AdminPassword123!`
4. Once signed in, click the user dropdown again to access all administrative dashboard sections:
   - **Company**: Edit company name, logo, contact phone, and email.
   - **Hero**: Edit title, badge, description, background image, and stats.
   - **About**: Manage company story, primary/secondary images, and features with the icon dropdown picker.
   - **Services**: Manage services, service section description, and promotional card.
   - **Records**: Manage company track record statistics.
   - **Projects**: Upload new projects, assign categories, and reorder.
   - **Categories**: Manage project filter categories.

## ⚠️ Important Note Regarding ImageKit & Uploading New Images

- **The Seeded Data**: All initial data generated by `npm run seed` uses local static files stored in `frontend/public/images/` and does not need ImageKit to display.
- **Uploading / Replacing Images in the Dashboard**:
  When you upload **new images** or **update existing images** through the admin dashboard (e.g. changing the Hero background, About images, Service banner, or adding new Projects):
  - The backend uses **ImageKit** (`IMAGEKIT_PUBLIC_KEY`, `IMAGEKIT_PRIVATE_KEY`, `IMAGEKIT_ENDPOINT_URL`) to upload and store image files.
  - **You must provide valid ImageKit credentials in `backend/.env` before uploading new images from the dashboard**. If valid credentials are not provided, image upload requests will fail with a 502 error.
  - When replacing a previously seeded image with an ImageKit upload, the system safely detects non-ImageKit dummy IDs and completes the update without crashing.
